# Backend Library m API - Intermediate Class 2026

Backend API untuk sistem manajemen perpustakaan yang dibangun menggunakan Express.js, Node.js, dan Prisma ORM dengan PostgreSQL.

## Fitur Utama
Autentikasi - JWT-based authentication dengan role management.

Manajemen Pengguna - Registrasi, manajemen profil, dan pembagian hak akses (roles).

Manajemen Buku - Operasi CRUD lengkap untuk katalog buku perpustakaan.

Kategori Buku - Pengelompokan dan organisasi buku berdasarkan kategori tertentu.

Peminjaman - Pelacakan sirkulasi peminjaman, batas waktu, dan pengembalian buku.

Cloud Storage - Integrasi dengan Cloudinary untuk upload gambar cover buku atau avatar profil.
